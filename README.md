I'm a Data Scientist working in a **MarTech** team, blending data science with marketing analytics to drive smarter decisions. I work across the full analytics spectrum — from exploratory data analysis to building and deploying ML models. I'm continuously exploring new fields in **AI and machine learning**, with a strong passion for turning complex data into clear, impactful insights.

- 🔭 Currently working on MarTech data products and predictive models

- 💡 Interested in the intersection of marketing, data, and AI
